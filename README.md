# Mongoose-with-Express-Mini-Chat-Box

Mongoose with Express – Mini Chat Box 💬

📌 About the Project

Mongoose with Express – Mini Chat Box is a mini web application built using Node.js, Express.js, MongoDB, Mongoose, and EJS. It allows users to create and view chat messages stored in a MongoDB database.

This project helped me understand how the frontend, backend, and database work together in a web application.

🚀 Features

💬 Create and send chat messages.

👀 View all chat messages.

📝 Store sender, receiver, and message details.

🗄️ Save chat data in MongoDB.

🔗 Connect Express.js with MongoDB using Mongoose.

🎨 Render dynamic pages using EJS.

📅 Store the date and time of each message.

🛠️ Perform basic CRUD operations.
